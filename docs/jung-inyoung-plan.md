# 정인영 개인전 〈희·노·애·락〉 모바일 도록 — 개발 계획

작성: 2026-11-12 · 목표 배포: 11-13(금) · 전시: 11-10 ~ 11-17, 갤러리 라온 3층 (김선례 개인전과 같은 기간, 같은 장소)

## 1. 결론

- 김선례 도록 코드를 **그대로 복사해 별도 사이트로** 만든다. 바꾸는 것은 문구, 색, 작품 이미지 세 가지뿐이다.
- 방명록, 꽃에 물주기, 관리자 페이지, QR 카드는 같은 기능을 쓰되 **저장 공간과 관리자 비밀번호는 따로** 둔다.
- 작품 이미지는 브로셔를 폰으로 찍은 사진이라 기울어져 있다. 반듯하게 펴고 잘라서 쓰되, 작가에게 **원본 파일을 받는 것**을 강하게 권한다.

## 2. 구조

| 항목 | 방식 |
|---|---|
| 코드 | 저장소 안에 `exhibition-jung/` 폴더를 새로 만든다 (`exhibition/`을 복사) |
| 주소 | 새 Vercel 프로젝트. 예: `jung-inyoung.vercel.app` |
| 저장 공간 | 새 Blob 저장 공간 (김선례 방명록과 섞이지 않게) |
| 관리자 | `/admin`, 비밀번호 별도 |
| 두 도록 연결 | 하단에 "같은 기간 함께 전시 중: 김선례 개인전 〈부귀영화〉" 링크 (서로 연결, 선택) |

**복사 방식을 고른 이유**: 남은 기간(전시 종료까지 5일)에는 공통 코드로 합치는 작업이 위험하다.
**단점**: 버그를 고치면 두 곳에 똑같이 반영해야 한다. 전시가 끝난 뒤 하나로 합치는 것을 권한다.
