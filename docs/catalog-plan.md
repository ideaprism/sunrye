# 김선례 개인전 〈부귀영화〉 모바일 도록 — 개발 계획

작성일: 2026-11-12(목) · 목표 배포: **11-14(토) 오전** · 전시: 11-10 ~ 11-17

## 1. 결론

- 기존 `sunrye` 저장소(Next.js 15)에 **도록 한 페이지를 새로 만들고, 기존 가짜 콘텐츠 페이지는 공개에서 내린다.** 새 프레임워크를 고르는 데 시간을 쓰지 않는다.
- 방명록은 Supabase 테이블 하나와 Next.js API 라우트 하나로 처리한다. 쓰기는 서버를 거치게 해서 30초 제한과 honeypot을 서버에서 검사한다.
- 도메인은 **이번에는 사지 않고 `*.vercel.app`로 시작하는 것을 권장**한다(아래 리스크 R2 참고).

## 3. 구현 구조

| 구분 | 내용 |
|---|---|
| 페이지 | `/` 한 페이지(표지 → 작가의 말 → 전시 안내 → 작가 소개 → 작품 11점 → 방명록 → 공유), 최대 폭 480px |
| 작품 상세 | 같은 페이지 위에 전체 화면 보기. 핀치 줌, 이전/다음, 닫기. URL에 `#work-3` 형태로 남겨 뒤로 가기 버튼이 '닫기'로 동작하게 함 |
| 방명록 API | `POST /api/guestbook`(검증, honeypot, IP·브라우저 기준 30초 제한) / `GET`은 Supabase에서 바로 읽기 |
| 인쇄용 | `/guestbook/print` — A4, 꽃 + 이름 + 날짜 + 글, 숨김 처리된 글 제외 |
| 데이터 | 작품·약력은 코드 안 데이터 파일로 고정(관리자 화면 불필요) |
| 글꼴·색 | HANDOFF 2장 그대로. 본문 18px 이상, 버튼 56px 이상 |
| 이미지 | WebP, `height:auto`로 비율 유지. 지연 로딩, 표지 이미지만 우선 로딩 |

## 4. 기존 사이트 처리

| 기존 페이지 | 처리안 |
|---|---|
| `/gallery`, `/about`, `/news`, `/contact`, `/family` | 공개 페이지에서 제외(삭제 또는 `/`로 이동) |
| `/admin/*` 관리자 | 쓰지 않음. 인증 없이 열려 있으면 그것도 내림 |
| `public/images/*` 기존 작품 사진 | 그대로 두되 도록에서는 참조하지 않음 |
