## 2. 디자인 규칙

- 주 관람층이 60~70대이므로 **본문 18px 이상, 버튼 높이 56px 이상, 굵은 항목명**
- 브로셔 색을 따른다
  - 작가명·강조색(초록): `#3D6B34`
  - 전시명 '부·귀·영·화'·연도 강조(빨강): `#A8323A`
  - 배경: `#FBFAF7`, 본문: `#1F1D1B`, 보조 글: `#4A4540` / `#5F5A55`, 구분선: `#E2DBD1`
- 글꼴: Noto Sans KR (400/500/700/800/900)
- 작품 이미지는 자르지 말고 원래 비율 그대로 (`object-fit: contain` 또는 `height: auto`)
- 이모지 아이콘은 쓰지 않는다 (방명록 꽃 스티커는 SVG로 그린다)

### 3-6. 방명록
- 순서: ① 꽃 고르기 → ② 이름(최대 20자) → ③ 한마디(최대 200자, 글자 수 표시) → [마음 남기기]
- 로그인 없음
- 꽃 스티커 5종 (SVG, 꽃잎 5개 + 가운데 원):

| 이름 | 꽃잎 | 가운데 |
|---|---|---|
| 모란 (기본 선택) | `#C2185B` | `#F2C230` |
| 해바라기 | `#F2C230` | `#7A4E1D` |
| 벚꽃 | `#F2B8C6` | `#D9718C` |
| 수국 | `#9DB4E0` | `#5470AE` |
| 목련 | `#F4EEE2` | `#C9A86A` |

- 목록: 최신순 카드 (꽃 + 이름 + 날짜 + 글), '남겨 주신 마음 N개'
- 이름·글이 비어 있으면 버튼 비활성

Supabase 테이블 제안:
```sql
create table guestbook (
  id uuid primary key default gen_random_uuid(),
  created_at timestamptz not null default now(),
  name text not null check (char_length(name) between 1 and 20),
  message text not null check (char_length(message) between 1 and 200),
  flower text not null check (flower in ('peony','sunflower','cherry','hydrangea','magnolia')),
  hidden boolean not null default false
);
alter table guestbook enable row level security;
create policy "read visible" on guestbook for select using (hidden = false);
create policy "anyone can write" on guestbook for insert with check (hidden = false);
-- update/delete 정책 없음: 삭제·숨김은 창균님이 Supabase 대시보드에서만
```
- 스팸 대비: 숨은 입력칸(honeypot) 하나, 같은 브라우저 연속 등록 30초 제한
- 전시 후 전체 방명록을 A4로 인쇄해 어머님께 드릴 예정 → 인쇄용 보기(`/guestbook/print` 등)가 있으면 좋음
