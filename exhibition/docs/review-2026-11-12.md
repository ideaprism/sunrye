# 도록 코드 리뷰 요약 (2026-11-12)

- 검토: 별도 세션(읽기 전용), 대상 `exhibition/`
- 이 파일은 요약본입니다. 원문 리뷰의 근거 파일과 줄 번호는 이 파일에 포함되어 있지 않습니다.
- 표 안의 사용량 한도 수치는 검토 세션의 기억에 의존한 값이라 확인이 필요합니다.

## 결론

보안 뼈대(XSS, 관리자 쿠키, PIN 저장 방식)는 정상입니다. 다만 전시 중 고쳐야 할 문제가 5가지 있습니다.

## 지금 고칠 것

| # | 문제 | 조치 |
|---|---|---|
| 1 | 방명록 목록 캐시가 60초라 Blob '고급 작업'(무료 월 약 2천 회, 수치 미확인)을 소진할 위험 | 캐시를 1시간으로 올림(글이 바뀌면 즉시 갱신은 유지) |
| 2 | "저장하고 물주러 가기"를 눌러도 실제로는 저장되지 않아, 중간에 나가면 글이 사라짐 | 버튼을 누르는 즉시 글을 저장하고, 물주기는 이어서 저장 |
| 3 | 물주기 완료가 실패해도 오류 메시지가 화면에 안 나옴 | 고르기 안내 띠에 오류 표시 |
| 4 | '내 글 고치기'가 모든 카드에 노출 | 내 글에만 표시하고 맨 위에 고정. 아래에 "고치기가 안 보이나요?" → 이름으로 찾기 → 비밀번호 |
| 5 | 목록에 내 글이 잠깐 안 보이면 '내 글' 기억이 영구 삭제됨 | 삭제하지 않음. 일부 파일 읽기가 실패하면 그 결과를 캐시하지 않음 |
| 6 | 비밀번호 5회 제한을 동시 요청으로 우회 가능 | 시도 횟수를 조회 전에 먼저 셈. 전체 분당 상한 추가 |
| 7 | 삭제하면 되돌릴 수 없고 백업 없음 | 방문자 삭제는 '숨김'으로 처리. 매일 저녁 인쇄본 PDF 저장 |
